# Block Quarry — Android app

The Playtoon block puzzle (ex-"Bloc Party"), packaged as a standalone Android app with Capacitor 8.
The game code is shared with the website (`../../js/blocks.js`, `../../js/i18n.js`, `../../css/style.css`):
`build.mjs` copies the game section of `../../index.html` into `src/index.html` and bundles the JS with esbuild.

| Folder / file | Role |
|---|---|
| `src/app.js` | App shell: settings (sound, language, remove ads, restore, privacy options), Android back button |
| `src/mon.js` | Monetisation: AdMob rewarded + capped interstitials, UMP consent, Google Play Billing (`remove_ads`) |
| `src/config.js` | Generated by `build.mjs` from env vars (`ADMOB_*`); Google **test** ad IDs by default |
| `android/` | Capacitor Android project (package `io.github.flocautank.blockquarry`, targetSdk 36) |
| `make-assets.mjs` | Draws icon, splash, Play icon and feature graphic → `assets/`; then `npx @capacitor/assets generate --android` |
| `tools/store-shots.mjs` | Play Store screenshots (1080×1920, EN + FR) → `store/screenshots/` |
| `tools/play-upload.mjs` | Uploads an AAB to a Play track through the Play Developer API (used by CI) |
| `store/` | Store listing texts, Data safety answers, **PUBLISHING.md** (the step-by-step guide) |

## Build

Locally (needs the Android SDK): `npm ci && node build.mjs && npx cap sync android && cd android && ./gradlew assembleDebug`.
In CI: `.github/workflows/android-block-quarry.yml` builds a debug APK and a signed release AAB (when the
`BQ_UPLOAD_*` secrets exist), starts the APK in an Android emulator, and can upload to the internal track.

## Monetisation rules

Reward videos are always optional; full-screen ads only between games, never in the first 5 minutes, at most one
every 4 minutes and one break in three; "Remove ads" is a one-time purchase; no ads before consent where required.
The website version has no ads (the game only calls `window.PT_MON`, which only the app provides).
